### 为什么不能让模型直接调用 `splitQaTool.execute()`，而必须经过 Registry 和 Dispatcher？

1. 因为模型不能执行 TS 函数，只能返回结构化的意图，真正执行的是 Node Harness
2. Registry 的作用是把函数名映射到指针的 execute 函数上
3. Dispatcher

```js
	找到 Tool
	→ 校验参数
	→ 检查权限
	→ 执行 Tool
	→ 捕获异常
	→ 记录日志
	→ 返回统一结果
```

### harness 各个模块是干什么的

Loop 让 Agent 能行动
Tool 让 Agent 能操作外部世界
RAG 让 Agent 能查询资料
Context 让模型处理当前请求
Memory 让 Agent 能延续过去。


**Trace + Web-Tap 是一个“进程内事件采集 + 实时推送 + 前端投影展示”的 Agent 调试系统**

**核心链路是：**
Agent 业务代码 -> Tracer → 生成 TraceEvent → MemoryTraceStore 保存 → SSE 推送 → Web-Tap 转换成 UI 状态。
1. Tracer 负责生成和关联事件
2. TraceEvent 是事实数据
3. TraceModule 标识事件来源
4. Web-Tap 是基于 TraceEvent 构建的只读观察层，通过 MemoryTraceStore + SSE 实时把 AgentLoop 投影成可视化执行轨迹

## 一、Trace 层实现

### 1. Agent 业务层不直接记录日志

```
tracer.span(
  "tool.call",
  input,
  async(span)=>{
      const result = await tool.run();
      span.setOutput(result);
  }
)
```
### 2. Tracer 是核心控制器

`Tracer` 内部维护：

```
AsyncLocalStorage<ActiveTraceContext>
```

用于保存当前上下文：

```
当前执行环境
{
	 sessionId,
	 traceId,
	 spanId,
	 parentSpanId
}
```

这样异步调用中：

```
Agent
 |
 await LLM
 |
 await Tool
 |
 await Memory
```

不用手动传：

```
traceId
spanId
```

Node.js 会通过 AsyncLocalStorage 自动恢复。
### 3. Span 生命周期如何实现

一次 Span：

```
开始
 ↓
生成 spanId
 ↓
publish(start event)
 ↓
执行用户逻辑
 ↓
publish(end event)
 ↓
结束
```

异常：

```
publish(error event)
```

对应代码逻辑：

```
runSpan()
  create spanId
  publish(start)
  await operation()
  publish(end)
catch
  publish(error)
```

### 4. TraceEvent 是最终数据格式

```
Event Stream
```

例如一次 Tool：

```
{
 name:"tool.call",
 phase:"start",
 module:"tool"
}
{
 name:"tool.result",
 phase:"event",
 module:"tool"
}
{
 name:"tool.call",
 phase:"end",
 durationMs:300
}
```

TraceEvent 保存：

```
{
 traceId,
 spanId,
 parentSpanId,
 sequence,
 timestamp,
 module,
 name,
 phase,
 data
}
```

## 二、MemoryTraceStore 如何工作

MemoryTraceStore 是当前 Trace 的存储层。

职责：
1. 保存事件
2. 提供历史查询
3. 提供实时订阅

结构：
```
            TraceEvent
                 |
          MemoryTraceStore
          ┌──────────────┐
          │ events[]     │
          │ listeners[]  │
          └──────────────┘
	             |
	       subscribe(listener)
	             |
	          Web-Tap
```

## 三、sanitize 层

数据流：

```
TraceEvent
   |
sanitizeTraceEvent()
   |
MemoryTraceStore
```

当前主要处理：

```
api-key
authorization
headers
env/environment
recalled_memory
```

避免：

```
Trace
 ↓
泄露用户数据 / Token
```

## 四、Web-Tap Server 实现

**Web-Tap 本质是： Trace 数据的读取和实时转发层**

入口：

```
observe.ts
```

启动：

```
MemoryTraceStore
       +
Tracer
       +
TapServer
```
#### 1. HTTP 拉历史

接口：

```
GET /api/events
```

返回：

```
[
 event1,
 event2,
 event3
]
```

#### 2. SSE 实时流

接口：

```
GET /api/events/stream
```

流程：

```
TraceEvent产生
      |
store.emit()
      |
listener触发
      |
server.write()
      |
browser收到
```

# 放宽 structure_interview 回答窗口校验

## 目标

避免 LLM 漏绑部分回答轮次时中断完整面试分析流程，同时保留最低限度的证据边界。

## 行为

- `answerTurnIds` 可以是程序计算出的回答窗口的子集，也可以为空数组。
- `answerTurnIds` 仍不得重复、不得引用非候选人轮次、不得引用回答窗口之外的轮次。
- 原文片段、面试官轮次覆盖、问题簇连续性、顺序等其他校验保持不变。
- 不自动补全模型遗漏的回答轮次，输出继续反映模型的语义判断。

## 实现范围

仅修改 `structurer.ts` 的回答窗口集合校验及对应测试。不加入日志、独立调试入口或 Prompt 重写；这些属于后续独立任务。

## 验证

- 新测试证明非空回答窗口允许模型返回空数组。
- 新测试证明允许返回回答窗口的部分候选人轮次。
- 既有测试继续证明重复、非候选人和窗口外引用会失败。
- 运行 `structurer` 聚焦测试、相关面试测试和 `git diff --check`。

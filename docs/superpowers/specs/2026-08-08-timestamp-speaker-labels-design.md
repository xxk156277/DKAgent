# 时间戳角色标签兼容设计

## 目标

让 `split_qa_pairs` 在保留现有冒号标签支持的同时，识别以下面试稿格式：

```text
面试官  08:32
问题内容

求职者  08:40
回答内容
```

## 最小改动

- 扩展角色标签匹配规则，允许角色名后出现冒号，或空白加 `HH:MM` 时间戳。
- 将“求职者”加入候选人角色集合。
- 修正工具 JSON Schema：必填字段由不存在的 `transcript` 改为 `transcriptPath`。
- 不修改 Agent Loop、Provider 或工具调用协议。

## 数据流

CLI 将文件路径交给模型，模型以 `transcriptPath` 调用 `split_qa_pairs`；工具读取文件后识别标签并按“问题后紧邻回答”的方式生成问答对。

## 错误处理

保留现有行为：文件过短、无法识别标签或没有完整问答对时返回 `input_error`。

## 验收

- `test/test-short.md` 拆出 1 组问答。
- 原有 `面试官:` / `候选人:` 格式继续通过。
- Phase 1 测试和类型检查通过。

## 不在本次范围

- 无角色标签的原始文稿。
- 多人访谈、说话人推断和语义拆题。
- Agent Loop 重构。
